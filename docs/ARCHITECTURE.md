# 🧠 GENX AI HOUSE BRAIN ARCHITECTURE

GENX AI House Brain operates as an AI operations manager coordinating development, cloud infrastructure, and physical edge devices.

```
                       Jules
              (Planner / Orchestrator)
                       │
     ┌─────────────────┼─────────────────┐
     ↓                 ↓                 ↓
 Cursor IDE        VS Code           Warp Terminal
 (AI Engineer)     (Universal IDE)   (System Control)
     │                 │                 │
     ↓                 ↓                 ↓
 Git Repository → GitLab → CI/CD → Deployment
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓

                       │
```

## 🤖 Role Assignment Matrix

| Layer | Tool | Specialty / Role |
|---|---|---|
| **AI Manager (CEO)** | **Jules** | Planner, orchestrator, task assignment, progress tracking |
| **Coding Brain** | **Cursor** | AI coding engineer, refactoring, codebase search, MCP integration |
| **Terminal Console** | **Warp** | AI command console, server commands, docker control, logs |
| **Universal IDE** | **VS Code** | Extensions, Docker, SSH, remote debugging, control room |
| **Professional IDE**| **JetBrains** | Deep language analysis, PyCharm/IntelliJ suite |
| **Cloud Lab** | **Replit** | Rapid cloud experiments and browser dev |
| **Source Memory** | **GitLab** | Version control, CI/CD pipeline execution |
| **Backend** | **Firebase** | Firestore database, Auth, Hosting |
| **Infrastructure**| **Google Cloud**| Cloud Run, BigQuery, GKE |
| **Human Interface**| **Edge Copilot**| Browser AI dashboard & assistant |
| **Physical Edge** | **BLUEDIM Mini PC**| Local AI edge server node |
