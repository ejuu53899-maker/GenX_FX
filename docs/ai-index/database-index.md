# 💾 Database Index

Index of data structures, persistence directories, and schemas.

## 📁 File-Based Learning & Memory Storage (`data/`)

- `data/memories/`: Successful execution memories (`memory_*.json`)
- `data/experiences/`: Complete experience records (`exp_*.json`)
- `data/failures/`: Failure logs and error analyses (`failure_*.json`)
- `data/improvements/`: Self-correction plans and skill version bumps (`improvement_*.json`)
- `data/usb_drive/`: Exported skill packages (`skill_*.json`) & system config backups
- `data/emergency_logs/`: Emergency stop backups (`emergency_backup.log`)
